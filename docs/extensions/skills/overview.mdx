Tools describe individual operations. Skills provide the instructions for using
those operations together: a workflow, the decisions along the way, and any
supporting reference material. Skills over MCP lets servers publish those
instructions alongside their tools, so agents can discover and read them through
the same connection.

A skill is a directory containing a `SKILL.md` file and optional supporting
files. The format follows the [Agent Skills specification](https://agentskills.io/specification).
This extension defines discovery and retrieval over MCP.

## Why serve skills over MCP?

- **Keep instructions with the service.** Publish workflows alongside the tools
  they describe and maintain them on the server.
- **Discover available workflows.** Clients can find the skills a connected
  server offers without a separate installation source.
- **Load context as needed.** Clients can inspect skill metadata first, then
  retrieve instructions and supporting files when relevant.

## How Skills work

1. **Capability detection.** The server advertises
   `io.modelcontextprotocol/skills` alongside its resources capability.
2. **Discovery.** Clients use `skills/list` to discover available skills and
   `skills/get` to look up a skill by URI.
3. **Retrieval.** Clients read instructions and supporting files on demand
   through `resources/read`, verifying static content against the skill's manifest.
